// PRIORITY ISSUES
P0

Primary action hidden in collapsed sheet

The start/stop spoofing button is inside a bottom sheet with 72dp peek height. The user must discover a gesture to find the most important action. For an operate surface with real-time location control, the primary control must be visible without discovery.

FIX: Move start/stop to a FAB or BottomAppBar. Sheet = configuration only. → /design relayout
P1

No loading states

Route fetching, geocoding, and location loading are silent operations. No CircularProgressIndicator or shimmer anywhere. Users see nothing happening and may tap multiple times.

FIX: Add progress indicator in route card, loading dot in search bar, map overlay shimmer. → /design interaction
P1

Joystick invisible until spoofing starts

JoystickOverlay only renders when isActive=true. The text says "Drag the joystick" but there's no joystick visible. Users cannot preview or practice the control before committing to start.

FIX: Show joystick in dimmed preview state when mode is selected but not active. → /design interaction
P1

Dead FilledTonalIconButtons in history

History cards use FilledTonalIconButton(onClick = {}). They look interactive (filled, tonal, elevated) but do nothing. Users will tap and get no response — a broken affordance signal.

FIX: Remove the button and use plain Icon, or give it a real action (replay route). → /design interaction
P2

ALL CAPS primary button text

"START SPOOFING" / "STOP SPOOFING" in all caps reads as generated. M3 labelLarge is already medium-weight at 14sp — the caps add shouting without adding meaning.

FIX: Sentence case: "Start spoofing" / "Stop spoofing". → /design typeset
P2

No custom typography — most common AI tell

Typography() with zero overrides. No font, no line-height, no letter-spacing tuning. Renders default Roboto with stock M3 scales.

FIX: Set bodyLarge line-height to 24sp. Add letter-spacing to labelLarge. Consider display font for coordinates. → /design typeset
P2

No haptic feedback

A spoofing app is inherently tactile — joystick drag, mode switch, start/stop. Zero HapticFeedback calls anywhere. Silent controls in a device with a vibration motor.

FIX: Light haptic on joystick grab, medium on mode switch, confirmation on start/stop. → /design interaction
P2

Generic color palette — Google Maps blue

SeedPrimary = #1A73E8 — exactly Google Maps blue. With green secondary. Indistinguishable from Maps, Waze, or any geo tool. App has no owned color identity.

FIX: Choose a hue with intent — stealth dark green, tactical amber/copper, or deep violet for privacy/obfuscation. Tint neutrals toward brand hue. → /design recolor
